HOW TO ADD OR CHANGE SPONSOR LOGOS

1. Put the logo file in this folder (PNG, JPG, WebP or SVG).
2. Open: src/components/home/SponsorsCarousel.tsx
3. Edit the sponsors list, for example:
   { name: "PETRONAS", logo: "/sponsors/petronas.png" },

For the best result, use a transparent-background logo with a wide aspect ratio.
